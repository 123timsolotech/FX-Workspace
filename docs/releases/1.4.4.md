# FX Workspace 1.4.4

Tor built in, searches that reach forums and Q&A sites, a page for everything the app keeps on your PC, a clear
way to quit, and a calmer, steadier app.

**Updating:** from 1.4.2 or 1.4.3, Settings › About › **Check for updates** › **Update now**. From older versions,
run `FX-Workspace-Setup-1.4.4.exe` over them. Your chats, settings, keys and models stay as they are.

## Tor, built in

- **The installer brings Tor with it** - the Tor Project's own Windows bundle, its signature checked against the
  Tor Browser developers' key when the installer is built. Nothing else to download, install or start.
- **Settings › Web search and network › Search through Tor:** one switch, and web searches and the pages it reads
  go through Tor - the sites don't see your IP. Everything else keeps its route.
- **It shows how it's doing:** "Connecting… 63%", then "Connected in 5 s". **New identity** gets new circuits;
  **Try again** after a failure shows Tor's own reason.
- **Never direct by accident:** while Tor connects, a search waits for it; if it can't connect, the search is
  blocked, not sent around it. Each chat gets its own Tor circuit.
- **Bridges** for networks that block Tor: Snowflake, or obfs4 with lines you paste.
- **Searching through Tor works well:** DuckDuckGo through its own onion address (it doesn't refuse Tor); a site
  that refuses one Tor exit is tried once on another; one that still refuses says so. `.onion` links open only
  through Tor.
- Tor runs only while something uses it and closes with the app. A Tor you run yourself (Tor Browser) can still
  be used instead.

## Search that reaches forums and Q&A sites

- **Settings › Web search › Forums and Q&A sites too** (on in Standard mode): alongside the web search it also
  asks Hacker News, Stack Exchange (Stack Overflow, Super User and more), Discourse forums (Home Assistant, Python,
  PyTorch, Roblox, Godot, Level1Techs and others), Lemmy, GitHub issues, Wikipedia and arXiv - picked by the kind of
  question: errors go to Q&A sites and issue trackers, "is it worth it" questions to forums, science to papers.
- **More phrasings:** the exact error text in quotes, and the way people write fixes up ("… solved").
- **One ranking from all of them:** a page several searches agree on rises; the assistant sees what each result is
  ("Q&A · accepted answer · score 42").
- **Measured** on 18 real questions: an answer in the top 5 for every one of them, against 89% for a web search
  alone - including when DuckDuckGo refused.
- Every source is asked honestly, through your network route (through Tor when that's on), paced; a site that
  refuses is skipped and named. Reddit isn't included - it refuses requests without a key.
- When DuckDuckGo stops answering, it's skipped for a minute instead of every search waiting ~20 s for it.

## Your data and files

- **Settings › Data and files:** everything the app keeps on this PC, largest first, with its size - chats,
  deleted chats, images, videos, music, attached files, research notes, run history, logs, the assistant's browser,
  voice and more.
- **Open** shows any of them in File Explorer, or the whole data folder.
- **Clear…** empties one kind - to the Recycle Bin, or for good if you tick "Skip the Recycle Bin". Clearing chats
  keeps your pinned ones unless you untick it. It never touches anything outside the data folder or your models,
  waits while a reply runs, and can't be used from the phone.

## Quitting, and no more stray tray icons

- **A power button** at the bottom of the sidebar (and "Quit FX Workspace" in the command palette and in Settings ›
  Appearance) turns everything off: the app, the server and the model. Closing the window still only hides it in the
  tray.
- **No more icons left in the tray:** when the app had been closed by force (an update, Task Manager), its tray
  icon stayed until the mouse passed over it - they piled up and looked like many servers running. The app now
  removes its icon as it quits and clears leftover ones when it starts.

## Calmer and steadier

- **One moving thing at a time:** while it works, only the thinking mark moves. The "Working" chip, dots, badges
  and the background glow hold still; a pulse now means only "it needs you". No more floating incognito ghost or
  rushing Aurora sky. The thinking marks move slowly and steadily, and the words don't change every few seconds.
- **It says when a model is loading:** "Loading Qwen 3.5 4B into memory · 12s" instead of a thinking phrase.
- **No surprise model swaps:** an image from earlier in a chat no longer switches your chosen model to a vision
  model on every message (two reloads a message).
- **Replies talk to you, not about you:** no more "The user said something vague, I should clarify…" or "your
  message was just 'okay'" at the start of a reply.
- **Research:** "retry" picks up the last stopped research instead of researching the word "retry"; the progress
  bar follows the work.
- Sites without an icon get a coloured letter tile.

## Known issues

- **DuckDuckGo can block an address that searches too much in a row** for some hours; searches then fall back to the
  forum and Q&A sources (or add a Brave key in Settings › Web search).
- **Deep search** - the full mode that reads whole forum threads and searches again for what's missing - is planned
  for the next version; this one brings its sources and ranking.
- Discord and Slack stay Beta.
