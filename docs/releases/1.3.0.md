# FX Workspace 1.3.0

Released 2026-10-16. The first release with a Windows installer: download `FX-Workspace-Setup-1.3.0.exe` and run it.

## Desktop app

- FX Workspace opens in its own window (Electron) instead of a browser tab. The page is the title bar, and the window buttons follow the theme.
- A tray icon. Closing the window stops the server and llama-server cleanly.

## Setup wizard with updates

- A per-user install (no admin) with a models folder and options to choose.
- A newer installer updates in place and keeps your chats, settings, keys and models.
- Settings › About shows the version and checks GitHub for updates.

## Settings › Models

- Each model shows its maximum context and the largest context that fits on your GPU.

## A lighter, faster UI

- A centred home, a slim one-line chat list, compact profile and model rows.
- Gold accent by default (terracotta is still in Settings), and the Fx mark follows the theme.
- Theme switches went from 2 s to 0.2 s and saves from 0.6 s to 16 ms. Settings › Models opens instantly instead of taking 16 s, because model headers are cached on disk.

## Fixes

- Asking to close the chat now closes the chat (it was sent to the desktop tool instead).
- The chat limits' abuse check was fixed and tested on a real model.
- The system prompt and skills loading were clarified.

## Other

- Linux: the launcher and desktop app run there; Windows-only packages are marked.
