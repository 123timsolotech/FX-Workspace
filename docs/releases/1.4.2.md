# FX Workspace 1.4.2

A big release: you can see what each chat costs the model, the app keeps working with its window closed, you can reach it from your phone or from Discord, Slack and a webhook, it knows who it is, and risky tasks can run sandboxed. On a local model, context and speed are the budget, so every new part shows what it costs, runs nothing unasked, and stays off until you turn it on.

**Still beta:**
- **Fx Labs** and the **AI-inspired appearances**, as in 1.4.1.
- **Discord and Slack.** They're built and tested against recorded messages, but not yet with a real bot. The webhook is not beta.
- **The MoE cache test** and the **NCM story writer** in Labs - new, and not yet run on many PCs.
- **Windows Sandbox runs** - they need the Windows feature switched on once (one admin step; the app explains it).

**Updating:** run `FX-Workspace-Setup-1.4.2.exe` over 1.4.1. It closes the app, keeps your chats, settings, keys and models, and updates only the app's own files.

## See and control what the model spends

- **Token breakdown.** Click the context meter to see the next request split into its parts: system prompt, soul, memory, each tool group and each MCP server, skills, history and the room kept for the reply. The numbers come from the loaded model's own tokenizer.
- **Tools off per chat.** Pills under the message box turn tool groups and single MCP servers off for this chat. They're saved with the chat, and the breakdown shows the saving at once.
- **Chat status dots** in the sidebar: running, waiting for your approval, error, or interrupted (the app closed mid-reply), with "Continue".
- **Background monitor** in Settings › This PC: every model call you didn't ask for (warm-up loads, chat titles, routines), with tokens and time, and a switch that blocks them all.

## Keeps working when the window is closed

- **Close to tray.** Closing the window hides it; replies, routines and the model keep going. Quit from the tray menu. A note explains this the first time, and a setting switches back to "closing quits".
- **Done notifications** when a long task finishes or needs your approval. Click one to open that chat.
- **Start with Windows**, optionally hidden in the tray.
- **Free the GPU when hidden:** the model unloads after 5-60 minutes with the window hidden and nothing running, so a game isn't fighting the AI for video memory.
- **The mini window is built in** and replaces the Edge overlay. Open it from the top bar, the tray or Ctrl+Alt+M. It snaps to a corner or follows Roblox Studio, can be see-through and click-through, stays on top, and has a small chat strip (your last message, the reply, Stop and a line to send). The assistant can move, resize or hide it when you ask ("put yourself in the corner while I play").

## Use it from your phone

Off by default; switch it on in Settings › Remote access.
- **Your network only:** your Tailscale address (recommended, it's encrypted) or your home network. Public addresses are refused.
- **A password is required.** It's stored as a strong hash, with a lock-out after repeated wrong tries and a list of signed-in devices you can sign out.
- **A QR code** for the address, and "Add to Home screen" for a phone shortcut.
- **From a phone** you can chat, approve or refuse steps, and read results. Settings, API keys, remote-access controls and screen control are refused from the phone.

## Discord, Slack and a webhook

Settings › Channels.
- **Only you.** A message from an allow-listed account starts a turn in that channel's own chat; anyone else is ignored and logged. The reply goes back to the channel.
- **The listener is never blocked.** While a turn runs, the channel still hears "stop" and your approvals.
- **Approvals in the channel:** buttons in Discord and Slack (Slack uses Socket Mode, so no public address is needed), a one-time link for the webhook. Sending a message on your behalf still always asks.
- **Webhook** for Home Assistant, n8n, iOS Shortcuts and the like: a local address with a secret, on your home network or Tailscale.
- Discord and Slack need a bot token from you, and connect only in Direct network mode.

## Who it is and what it remembers

- **A Soul file** (Settings › Memory) says who the assistant is. It's sent with a header telling the model the file describes *itself*, and "About you" now says plainly that it describes *you*, so a model no longer mixes the two up.
- **A new fact replaces the old one** about the same thing (your name, where you live, "my X is ...") instead of adding a duplicate.
- **Memory as linked notes** in `data/memory`, one per topic, with a graph in Settings › Memory and a "Tidy up" button.
- **A short overview** at the start of each chat: topic names and counts only. The facts themselves still go in only with messages they match. It can be switched off.
- **Work and Assistant chats.** Project chats are Work: reminders, memory writes and notes only when you ask. Every other chat is Assistant. Each kind carries only the tools it needs.

## Sandboxed chats

- **Switch a chat to Sandboxed** from the context breakdown. File tools then reach only that chat's scratch folder, and commands run as a restricted Windows process: low integrity, no access to your folders, capped at 2 GB and half the CPU. Screen control is off. Copying a result out asks first and never overwrites.
- **Windows Sandbox** for unknown programs: "run this download in the sandbox" opens a throwaway Windows with networking off and only that file shared, read-only.

## Speed and Labs

- **MoE cache test** (Settings › Models) for mixture-of-experts models: it runs the same prompt with and without `--moe-cache-mib` at a few sizes that fit your free video memory, and keeps a size only if writing gets at least 5% faster and prompt speed doesn't drop. About 15 minutes per model.
- **NCM story writer** (Labs › Research models): HazyResearch's TinyStories model writes a story level by level, from a rough outline to the full text, with each level shown as it lands, and a speed comparison against your chat model. Setup downloads 578 MB. This model writes stories from scratch; it can't continue a story start you give it.

## Safer and fairer

- **Prompt-injection defences.** Text hidden on web pages is no longer read. An address a page could have built asks before it opens, and one carrying your key is refused. Disguised letters no longer slip past the check.
- **Political and controversial questions** are no longer refused as "outside this app's limits".
- **A "Relaxed limits" switch** at the top of Settings › Privacy, for uncensored (abliterated) models, turns every optional check off at once. Sexual content involving minors stays refused.
- **Switching appearances** no longer leaves parts of the old one behind.

## Known issues

- On some PCs Focus Assist sends the notifications straight to the Action Center without a pop-up.
- "Add to Home screen" makes a shortcut; a fully installable phone app needs HTTPS, which plain Tailscale and home-network addresses don't have.
- Right after the app starts, its hidden approval window can take the keyboard focus for a moment.
